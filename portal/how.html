工作流程

机器每天在网上收集与水务项目有关的公开信息,判定后挂到具体的项目机会上;人在此基础上立项、跟进、做判断; 报告、日历和这页问答都从同一张台账里出。下面按「流程 → 节奏 → 分工 → 规矩 → 问答」说清楚。

1. 一条主线:线索 → 商机 → 跟进 → 报告与日历

机器公开数据
信源每天定时抓采购门户、多边银行、新闻与 RSS
线索每条判定:相关吗、什么类别、哪个领域、哪国、中文摘要、金额与截止日
商机线索挂到已有项目;像新项目的建一条「建议」商机,每条事实带出处
时间节点截止、开标、授标、签约等公开日期,过期自动改「已发生」
定期报告日报、周报、月报、重点国别的招标监测自动生成;配了模型的多一段研判
人业务数据
线索处理确认线索归属;对建议商机决定「跟踪」或「不跟进」
我方阶段跟踪中 → 准备投标 → 已投标 → 中标 / 未中标;改阶段自动补一条跟进
跟进记录做了什么、了解到什么、怎么判断、下一步与到期日
日历公开节点 + 跟进到期排在一起;可导出或订阅到手机日历
国别 / 项目报告在页面上要一份,2 分钟内出 Word

线索、国别、商机、跟进记录是四个核心对象;信源、时间节点、城市、报告、报告模板、成员是支撑对象。每个对象的属性、状态流转与口径见本体页。

2. 每天的节奏

每天 08:00程序自动更新到最新版(页面、后台任务)。
每天 08:30采集全部信源 → 判定新线索 → 挂接或建议商机 → 写时间节点;完成后自建当天的日报,「线索分析」页顶部显示正文。
每 2 分钟补全同事上传的线索(抓网页、补摘要与国别);生成报告表里「待生成」的报告;人改了商机阶段就补一条跟进。
每天第一个周期把已过期的时间节点改成「已发生」。
周一 09:00 · 每月 1 日 09:30自建上周周报、上月月报;周一还给每个重点国别自建一份上周的招标监测。
每月 1 日按世行、IMF 接口刷新各国宏观与水务指标;出现新国别时第二天补齐。

5. 首页的问答是怎么回答的

  1. 听懂:把一句话翻成筛选条件——对象(线索 / 商机 / 节点 / 报告)、国别、时间、领域、类别、资金来源、阶段、怎么呈现(数一下 / 列清单 / 按什么分)。配了模型用模型翻,没配按词表认。
  2. 查表:页面带着你的登录身份直接去台账里数、列;模型从头到尾看不到表里的任何一条数据,只看到你的问题。
  3. 呈现:数字卡、清单或按国别 / 类别 / 月份的柱图,同一口径下给出去「线索总览」「商机总览」「日历」「报告」的链接;要报告的问题转到报告页排队生成。

所以它答的是「表里有什么」,不是「网上有什么」;它不会编数据,也不会替你改表。
