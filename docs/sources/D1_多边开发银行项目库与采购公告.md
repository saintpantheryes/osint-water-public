# 多边开发银行项目库与采购公告 — 数据源实测

> 本文是 2026-09-21 对一组 **39 个发展中国家样本**(世行 IDA/IBRD 混合;具体国别清单由使用方在 profile 中配置,本文不列)的数据源可得性实测记录。文中"样本国"均指该集合。已去除任何组织专属内容;实测脚本与样本文件保存在私有证据目录,未随本文发布。


## 结论与建议
## 结论:MDB/DFI 水务项目与采购数据能否程序化获取

约 70% 能程序化获取,且不需要任何付费或登录。世行系、IATI 系、AIIB、EBRD、EIB、IDB、AFD 都有 API、批量文件或可解析的内嵌数据。ADB 和 AfDB 官网被 Cloudflare 挡住,但两家的 IATI XML(ADB 另有官方 RSS)是开放的。阿拉伯系基金、BDEAC、NDB 只有 HTML 或新闻稿。

需要提前说明:这批数据源产出的约 90% 是主权贷款项目下的 EPC 和咨询机会,不是 PPP/BOT/股权机会。投资类线索要单独从下面几类"私营窗口"里取,量小但价值高:
- IFC 的披露数据。
- EBRD PSD 里标记为 `Private` 的项目。
- AIIB 标记为 `Nonsovereign` 的项目。
- IDB 标记为 `Non-Sovereign Guaranteed` 的项目。
- Proparco(AFD 私营窗口)的数据集。

### 推荐的第一批接入顺序

1. **世行项目库 v3** `search.worldbank.org/api/v3/projects`
   - 39 个样本国的 Active+Pipeline 一次请求就能拉全(实测 882 条)。
   - 客户端按部门码前缀、`sector_percent` 和关键词三重过滤出水务项目。
   - 这是"项目对象"的主干,Pipeline 项目带预计董事会日期(实测排到 2027 年)。
2. **世行采购公告** `…/api/v2/procnotices`
   - 用 `project_id` 关联项目库。
   - 用 `deadline_strdate` 取在开标的公告,用 `submission_deadline_date` 作截止日。
3. **世行文档 API** `…/api/v3/wds`
   - 给每个 Pipeline 或新批项目挂 PID、采购计划和 ESRS。
   - `txturl` 是纯文本直链,可以交给 LLM 抽取合同包、金额和实施机构。
4. **IATI 统一层** `d-portal.org/q.json`,备份用各家源 XML
   - 一次覆盖 ADB、AfDB、EBRD、IDB、IsDB、AFD、BMZ/KfW、JICA、BOAD。
   - 用 DAC 140xx 统一口径,适合做"各国水务资金盘子"和跨机构去重。
   - AfDB 和 ADB 的数据带 `status=1`(Pipeline)。
5. **管线与私营标记补强**
   - AIIB 的 `all-projects-data.js`:含 Proposed 状态和 Nonsovereign 标记。
   - EBRD 的 `filterlistservlet`:含 State/Private 标记。
   - EIB 的 `page-provider`:含 Under appraisal 状态。
   - IDB 项目 CSV:含 Preparation 状态和 NSG 标记。
6. **投资类线索**
   - IFC 的 Finances One 数据集 `DS00499`(日更,7118 条)。
   - IFC 的 IATI XML(部门用 NAICS 码,水务为 2213,含项目描述全文)。
   - Proparco 数据集。
   - IDB Invest 和 MIGA 放第二批。
7. **招标补充**
   - EBRD ECEPP:单页 HTML,约 4000 条,免登录。
   - ADB 的 Feedburner RSS:IFB、CSRN、proposed、approved、contracts-awarded 各一条。
   - AIIB 的 `ppo-data-all.js`。
   - IsDB 的 tenders 页面(HTML)。
8. **竞争情报**
   - 世行合同授予数据集 `DS00005`(292,139 条)。
   - 可按国别和水务实践统计中资及竞争对手的中标情况,例如实测 `supplier_country_code='CN' and borrower_country_code='UZ'` 命中 101 条。

### 关键坑(均有实测依据)

- **世行 v2 项目 API 已冻结在 2024-12-20**
  - v2 总数 22,729,v3 为 28,134。任务书和网上教程给的都是 v2,必须改用 v3。
- **v3 的部门分类是新旧两套并存**
  - 旧分类是两字母码(WA/WC/WF/WX,名称带 `FY17 -` 前缀),2024 年后的项目用三字母码(WWA/WWC/WWW/WWX)。
  - `mjsectorcode_exact` 这类参数在 v3 被静默忽略,返回的是全量。
  - Pipeline 项目约 42% 没有部门码,必须用关键词兜底。
  - `sectorcode` 会把占比很小的部门也列进去(例如能源项目里只占 8% 的供水),要用 `sector_percent` 设阈值。
- **世行采购公告 `procnotices` 的日期字段**
  - `submission_date` 是发布日,不是截止日。真正的截止日是 `submission_deadline_date`。
  - `strdate`/`enddate` 参数无效,`deadline_strdate` 有效。
  - 39 个样本国在开标的水务公告同一时点只有约 10 条,且多为 260 万美元以下的国内标。
  - 所以"机会识别"不能指望招标公告,要前移到 Pipeline、PID 和采购计划。
- **Cloudflare 和验证码**
  - ADB、AfDB、MIGA、IDB 主站和 data.adb.org 都是 Cloudflare 质询,GTAI 是 Radware 验证码,本次均未绕过。
  - ADB 的 robots.txt 明确禁止爬取 projects 和 tenders 的 CSV、RSS 路径。
  - 替代办法是 IATI XML、Feedburner RSS,或人工导出。
- **datacatalogapi.worldbank.org 会对 Python urllib 默认 UA 返回 403**,请求要带浏览器 UA。
- **前端内嵌的 APIM key**
  - IFC 搜索接口和 PPI API 都依赖页面里内嵌的订阅 key,复用属于灰色地带,本次未调用。
  - IFC 优先用开放数据集 `DS00499` 加 IATI 做主通道,再用 `project_url` 直达详情页。
- **IATI 的局限**
  - 数据滞后 1 到 2 个月。
  - WB、EBRD、IsDB、IDB 不报 Pipeline。
  - IFC 用 NAICS、CAF 用自定义部门码、EIB 没有 DAC 码,这三家在 `sector_group=140` 下查出来是 0 条,要按标题关键词查。
  - 官方 IATI Datastore 没有 key 会返回 401(可免费注册),d-portal 和 Datastore Classic 不需要 key。
- **IDB 采购公告 CSV 疑似停更**:元数据显示 2026-09-18 更新,但内容最新只到 2025-10-03。
- **非正式接口可能随改版失效**
  - AIIB、EBRD、EIB 用的都是网站内部接口。
  - 建议每个接入源做 schema 校验和报警。
  - AIIB 的采购 JS 文件不是严格 JSON,需要特殊解析。

### 覆盖缺口

- **区域**
  - 中部非洲样本国和太平洋岛国样本国主要靠 WB、AfDB、ADB、EIB,BDEAC 没有结构化数据。
  - 沙特和阿曼基本不在 MDB 主权贷款体系内。
  - 两国的海淡和污水项目是 SWPC、Nama 主导的 PPP,只有 AIIB 的 Nonsovereign 和 IsDB 零星覆盖,需要另接这两国的 PPP 单位或采购平台。
- **阿拉伯系基金**(SFD、KFAED、ADFD、BADEA、OPEC Fund):对中亚、西非、毛里塔尼亚很重要,但只有新闻稿,建议并入新闻和舆情通道。
- **真正的投资类管线**(各国 PPP 单位、特许权招商、私营水司并购)不在 MDB 数据里,需要下面几类源互补,均不在本次实测范围:
  - 国别 PPP 单位。
  - IFC Advisory(PPP 交易顾问)。
  - 付费情报库(IJGlobal、Infralogic、GWI DesalData)。
- **AfDB、ADB 的 SPN 招标公告**无法合规自动化,需要走 UNDB 或 dgMarket 聚合(付费),或者人工周查。
- **JICA、KfW、CAF、EIB 没有集中招标库**,招标由业主自行发布。

### 对系统建模的含义(供 visual-model 本体参考)

- 核心对象建议至少拆成五个:`FinancedProject`(出资项目)、`ProcurementNotice`(采购公告)、`ContractAward`(合同授予)、`Disclosure`(私营披露)、`Document`(PID、采购计划)。
- 关联键用各机构自己的项目号:WB 的 Pxxxxxx、ADB 的 5 位-3 位编号、AfDB 的 P-KE-E00-013、EBRD 的 5 位数字、IDB 的 PE-L1292、IATI identifier。
- `机会类型` 应作为一等属性,取值为主权 EPC、次主权 EPC+F、私营投资/PPP。
- 这个属性直接映射到各源的现成字段:Sovereign/Nonsovereign、State/Private、SG/NSG。

临时文件都在 scratchpad 的 `mdb/` 目录下,没有改动任何项目文件。

### World Bank Projects & Operations API v3(主用) — https://search.worldbank.org/api/v3/projects?format=json
- **category**: MDB项目库
- **access_method**: API(JSON),无需key
- **verified**: True
- **probe_evidence**: curl 'https://search.worldbank.org/api/v3/projects?format=json&rows=3&srt=boardapprovaldate&order=desc' → total 28134,首条 P518248 Burundi 2027-10-26 Pipeline;'...&status_exact=Pipeline&rows=500' → 331条,62条含WW*;5国全量:UZ137/KE369/PE299/NG382/MA368;id=P162263&fl=* 返回 milestones/geo_locations/isr_ratings 等50+字段
- **key_fields**: id, project_name, countryshortname, countrycode, status(Active/Pipeline/Closed/Dropped), boardapprovaldate(Pipeline为预计日期,实测到2027-10), totalamt, lendprojectcost, curr_ibrd_commitment, idacommamt, grantamt, borrower, impagency, closingdate, sectorcode, major_sectors[含sector_percent], theme_list, pdo, project_abstract, last_stage_reached_name(Concept Review/Board Approved…), public_disclosure_date, milestones, geo_locations(含经纬度), financers, loan_transactions, isr_ratings, indicators, cons_serv_reqd_ind;fl=* 返回全部,默认fl只有约20个字段
- **water_filter**: 两套部门分类并存:旧分类两字母码(WA卫生/WC供水/WF水务公共管理/WZ其它/AI灌排,major=WX),2024年后新项目用三字母码(WWA/WWC/WWF/WWW水资源/WWB固废/WWZ,major=WWX;AAI灌排;LLH水电)。服务端可用 sector_exact='FY17 - Water Supply^FY17 - Sanitation^...'(^=OR),但 mjsectorcode_exact/major_sector_code_exact 在v3被忽略(实测返回全量369)。最稳做法:按39 个样本国 countrycode_exact=UZ^KZ^... + status_exact=Active^Pipeline 一次拉全(实测882条),客户端按 sectorcode 前缀 W/WW/AI/AAI + major_sectors[].sector_percent>=30% 过滤;Pipeline 项目约42%无sectorcode(实测138/331),必须叠加项目名/PDO关键词(water|sanitation|wastewater|irrigat|desalin|eau|agua|saneamiento|assainissement)兜底
- **tos_notes**: 世行开放数据 CC BY 4.0;无key无明显限流(实测 rows=2000 一次返回);datacatalogapi 系列对 Python urllib 默认UA返回403,需带浏览器UA
- **update_frequency**: 准实时(v3 total=28134;proj_last_upd_date 最大 2026-06-22;Pipeline 预计批准日滚动更新)
- **value_for_investment**: high — 唯一能免费拿到'尚未批准(Pipeline)+预计董事会日期+金额+执行机构+PDO'的结构化源,是上游机会识别的主干;但本质是主权贷款项目(EPC/咨询机会为主,非股权投资)
- **notes**: 分页用 os(offset)+rows;多国用^连接;facet 用 fct=status_exact,sector_exact(top100)。
