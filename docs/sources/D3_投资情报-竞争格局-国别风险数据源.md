# 投资情报、竞争格局与国别风险 — 数据源实测

> 本文是 2026-09-21 对一组 **39 个发展中国家样本**(世行 IDA/IBRD 混合;具体国别清单由使用方在 profile 中配置,本文不列)的数据源可得性实测记录。文中"样本国"均指该集合。已去除任何组织专属内容;实测脚本与样本文件保存在私有证据目录,未随本文发布。


## 结论与建议
## 一、结论先行
从“投资(而非承包)”视角,**免费数据足以起步,但结构与招标类数据完全不同**:投资线索没有一个“全球在招 PPP 库”(GI Hub 管线已下线、SOURCE 公开管线 2026-08 起暂停——均实测),只能用 **“先例库 + 国别可投性指标 + 多路弱信号”** 三层拼出来。实测最重要的一个事实:世行 PPI 库 1990-2024 全部 1324 条水务 PPP 中,39 个样本国合计 293 条,其中**巴西 195 / 哥伦比亚 58 / 秘鲁 10,其余各国 ≤3,15 国为 0;2019 年后非巴西样本国只有 7 条**。含义:①大多数样本国“水务投资机会”是稀疏事件,系统应以**国别为主体、机会为事件**来设计,而不是期待一个大项目表;②真正有投资管线的是 海湾(沙特/阿曼,PPI 不覆盖)、拉美三国、摩洛哥、乌/哈,以及非洲少数 DFI 支持的单体项目(Kigali、Aghien、Mbezi 这类)。

## 二、免费即可起步的“投资机会信号源”组合(按接入顺序)
**第 1 批(一次性导入,1-2 天,全是结构化/已实测):**
1. 世行 **PPI 库**(dta/Excel 全量;45 字段含付费机制、政府支持、发起人、贷款行)→ “先例/竞争者/付费机制”底表。
2. **国别可投性指标包**:OECD CRC(PDF 已解析)+ LIC-DSA JSON(apiv2.worldbank.org/files?resourceName=dsa.json,69 国)+ WGI(新代码 GOV_WGI_*)+ WDI 宏观/汇兑代理指标 + JMP(WB API)+ Wikipedia 三大评级 + Chinn-Ito。全部免 key。
3. **中资足迹**:BU CLA CSV(非洲 1319 笔,水务 103 笔,已取)+ AidData CLG-Global 1.0(43.7MB zip,217 国,含 Water Supply & Sanitation 部门)。
4. 商务部 **国别指南** 196 册 PDF(39 个样本国全覆盖)→ LLM 抽取 外汇管制/PPP 法规/在地中资。

**第 2 批(持续信号,复用 water-tracker 现有 RSS 管道):**
5. **MEED RSS**(sector/water + 沙特/阿曼/摩洛哥国别 feed,实测可用)+ Utilities-ME + Zawya(HTML)。
6. **Google News RSS 查询矩阵**(39 个样本国 × {water, wastewater, desalination} × {PPP, concession, BOT, privatization} × 语种),并用 `site:` 覆盖 BNamericas / Smart Water Magazine / Partnerships Bulletin 等无 RSS 站的标题。
7. 区域 RSS:Engineering News 水务频道、ESI Africa、Trend、AKIpress、UzDaily、Astana Times、Daily Sabah、Hurriyet 等(均实测 200)。
8. **IFC 披露 API**(JSON 无 key)+ 其他 DFI 私营窗口项目页 → “已被验证可融资”的线索。
9. **cninfo 公告检索**(中国电建等“重大合同”公告,JSON)+ 见道网 → 竞合方动态。

**第 3 批(半手工):** 8-10 个重点国 PPP 中心页面做“变更监测”(Sharakat/原 SWPC、Nama PWP、ProInversión、BNDES Hub、ANI、KZPPP、PPPDA、Kenya PPP、ICRC)——多站对境外访问不稳(实测 6 个超时),不要指望全自动。

## 三、若公司愿意付费,最值的 2-3 个
1. **GWI WaterData + DesalData**(首选):唯一对 39 个样本国都有水务专业覆盖的源,含 PPP/海淡项目阶段、投标联合体、中标水价、水司档案、全球水价调查——正好补免费数据缺的“购水方/水价/竞标格局”。官网纯 JS、无 RSS、严格版权,免费层几乎不可用。
2. **MEED Projects**(若主攻沙特/阿曼):海湾 IWP/ISTP 是全球最活跃水务 PPP 市场,而 PPI 库不覆盖高收入国;免费 RSS 只有标题摘要。
3. **BNamericas**(若主攻秘鲁/巴西/哥伦比亚):拉美占样本国水务 PPP 先例 90%,其项目档案含阶段/capex/参与方/联系人。
- 不建议先买:IJGlobal(已并入 Green Street,实测跳转)/Infralogic —— 只在做存量并购时才值;BMI/Fitch —— 水务颗粒度不够;Devex Funding —— 偏承包/咨询。价格均需询价(未验证)。
- 另:**中国信保国家风险评级**不是买不买的问题,而是向公司内部要(投资评审必引)。

## 五、关键坑
- PPI 的 JSON API 需要订阅 key,**key 是页面前端内嵌的**(实测无 key 401、带 key 200):正式接入请用 dta/Excel 年度全量,API 低频补充,避免 ToS 争议。PPI 国家码非 ISO(刚果金=ZAR、东帝汶=TMP)。
- WGI 指标代码已改为 `GOV_WGI_*` 前缀;`IE.PPI.WATR.CD` 已无数据。
- IMF/OECD/世行 PPP 站/AfDB/MIGA/newIBNET 对浏览器 UA 的 curl 返回 403(Akamai/Cloudflare);IMF DataMapper 用默认 curl UA 反而 200;OECD 用 PDF 直链可绕过 HTML 页。
- 多个中国站与部分国家 PPP 站从境外出口超时(covec.com、camce、cgcoc、mofcom PDF、ncp.gov.sa、proinversion 等)——部署位置(境内/境外)会影响可达性,需双出口或重试。
- MEED RSS 无 pubDate;desalination.biz RSS 已基本停更;Construction Review 主 feed 已偏美国内容;BU 数据文件名带 hash 每版会变。
- 付费站只做“标题+链接+自家摘要”,不要存正文。

## 六、覆盖缺口
- **太平洋岛国(巴新/东帝汶/所罗门)与中非法语区**:无本地新闻 RSS、无 PPP 先例、无评级——只能靠 MDB 项目库(ADB/WB)+ Google News。
- **沙特/阿曼/波兰/土库曼**不在 PPI 库;沙特/阿曼靠 MEED+Sharakat/Nama;波兰靠 ppp.gov.pl(旧路径 404,未找到新入口);土库曼基本无公开管线。
- **并购/股权转让类机会**无免费结构化源(只能新闻信号 + 付费 Infralogic/GWI)。
- **购水方信用/水价**是免费数据最大短板(IBNET 取不到)。

证据文件目录:私有证据目录(ppi_water.json、ppi_selector.json、dsa.json、oecd_crc.pdf、bu_cla.csv、feeds_result.txt 等)。未修改任何项目文件。
