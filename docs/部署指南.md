# 从零部署(自己 fork、自己部署)

装好后是这样一套东西,都在你自己的一台云主机上:

- **Teable**(开源多维表格,AGPL 社区版)+ Postgres + Redis:唯一的数据库。线索、商机、国别、报告都是表里的行;帐号、权限也用它的。
- **Caddy**:自动申请 HTTPS 证书;把 `/portal/` 的页面交给浏览器,每个请求先问 Teable 这个人登录了没有(forward_auth)。
- **页面**(`portal/`):纯静态,在浏览器里以登录人的身份直接读写表格。
- **后台任务**(worker,`core/worker.py`):每天北京时间 08:30 采集信源、判定线索、出日报;每 2 分钟补全新线索;按需出 Word 报告;每月更新各国宏观数据。

程序在**核心仓**(本仓库,或你的 fork);你自己的配置放在另一个**私有配置仓**(profile、页面配置、可选的报告模板)。
主机上两个仓库各检出一份,每天 08:00 自动取 `main` 的新提交。

> 省事的做法:把 [README](../README.md#部署) 里那句话交给 AI 助手,它按 [AI_INSTALL.md](AI_INSTALL.md) 带你装;
> 或者准备好下面第 0 步的东西后直接跑 `bash deploy/teable/one_click.sh <密钥.pem> <主机IP> <域名> <你>/osint-water-private`,
> 它把第 1–4 步连起来做完(私有配置仓建一个空的就行)。下面是每一步分开做的说明。

## 0. 准备

- 一台公网云主机:2 核 4 GB 起,Ubuntu 22.04/24.04,root 能用密钥登录;安全组放行 22、80、443。
  主机在中国内地须 ICP 备案;不备案就选香港或海外节点。
- 一个域名(子域名即可),能加 A 记录。
- 一台装了 bash、git、ssh、Python 3.11+ 的电脑(macOS 或 Linux;脚本名里的 `_from_mac` 只是历史叫法)。
- 可选:DeepSeek 或 Claude 的接口密钥。没有也能跑,只用规则初筛,中文摘要与项目分析会弱很多。

## 1. Fork 核心仓、建私有配置仓

1. 在 GitHub 上 fork 本仓库(或直接克隆后推到你自己的仓库)。把它克隆到本机:
   ```bash
   git clone git@github.com:<你>/osint-water-public.git && cd osint-water-public
   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
   ```
2. 在 GitHub 上新建一个**私有**仓库(例如 `<你>/osint-water-private`),克隆到核心仓旁边,再挂成核心仓的 `private/`:
   ```bash
   git clone git@github.com:<你>/osint-water-private.git ../osint-water-private
   ln -s "$(cd ../osint-water-private && pwd)" private
   cp profiles/example/profile.yaml private/profile.yaml   # 按注释改:重点国别、行业口径、门槛、语种、模型
   ```
   `private/` 已被 `.gitignore` 排除,不会进核心仓。

## 2. 装 Teable 与 Caddy

```bash
bash deploy/teable/push_from_mac.sh ~/.ssh/<密钥>.pem <主机IP> <你的域名>
```

脚本会在主机上装 Docker,起 Teable、Postgres、Redis、Caddy,注册管理员、关掉自助注册、配每日备份,
最后把管理员邮箱、密码与接口令牌打印出来(主机上存于 `/opt/teable/ADMIN.txt`,只有 root 可读)。
然后在 DNS 里把域名指向主机 IP(用 Cloudflare 的话选「仅 DNS」),等一两分钟打开 `https://<你的域名>`,用管理员登录并改密码。

## 3. 建库、建表

在本机终端里(令牌只放在环境变量里,不要写进任何文件):

```bash
export TEABLE_URL=https://<你的域名>
export TEABLE_ADMIN_TOKEN=<ADMIN.txt 里的接口令牌>
.venv/bin/python -m core.schema --profile private/profile.yaml --dry-run   # 先看要建什么
.venv/bin/python -m core.schema --profile private/profile.yaml             # 建库「水务项目机会 新版」和全部表、字段、视图
```

建好后它把库、表、字段、视图的编号写进 `private/portal/config.json`,页面按编号取数。提交到私有配置仓:

```bash
cd private && git add profile.yaml portal/config.json && git commit -m "初始配置" && git push && cd ..
```

以后本体(`docs/ontology/ontology.yaml`)加了表或字段,重跑同一条命令即可(只增不删)。

## 4. 装后台任务与页面

1. 后台任务用的令牌:在 Teable 里(管理员或单独建一个机器帐号)生成一个**永不过期**的个人访问令牌,
   权限给这个库的读写。然后:
   ```bash
   bash deploy/teable/worker_token_from_mac.sh ~/.ssh/<密钥>.pem <主机IP>   # 按提示粘贴令牌
   ```
   令牌一过期,采集会悄悄停下来,所以一定选永不过期。
2. 装后台任务(在核心仓检出里运行;核心仓地址取本检出的 origin,也就是你的 fork):
   ```bash
   bash deploy/teable/worker_from_mac.sh ~/.ssh/<密钥>.pem <主机IP> <你>/osint-water-private
   ```
   脚本会打印主机生成的两把部署密钥(公钥),按提示分别加到两个仓库的 Settings → Deploy keys(只读即可);
   再按提示粘贴模型密钥(可留空)和可选的告警心跳网址。密钥写在主机 `/opt/teable/worker.env`,只有 root 可读。
3. 建议在 `worker.env` 里加一行 `OW_USER_AGENT=your-project/0.1 (+https://你的网址或联系邮箱)`:抓取时如实报上身份,
   信源方有问题能找到你。

装完打开 `https://<你的域名>/portal/`,登录后就是系统首页。第二天 08:30 之后会有第一批线索与日报。

## 5. 加人

自助注册保持关闭。在 Teable 的库里生成邀请链接(查看者只读,编辑者能改),发给同事;同事用邀请链接注册后就能登录页面。
没有邮件服务也没关系:邮箱只是登录名,Teable 不会发信。

## 6. 可选

- **报告模板**:程序自带一套中性的 Word 模板(`core/templates/`)。要用自己的版式,把同名文件放进私有配置仓的 `templates/`,
  或在页面「报告模板」表里上传。
- **国别信源**:除全球信源外,每个重点国可以加本国业主公告栏、当地招标网等,写在私有配置仓 `countries/<ISO3>/watch.yaml`,
  在 profile 那一国写 `watch: countries/<ISO3>/watch.yaml`。字段含义见 `core/watch/collectors.py`。
- **首页视频**:私有配置仓 `portal/media/` 下放 `hero.webm`、`hero.mp4` 与封面 `hero.jpg`。
- **站名与字体**:站名在 `portal/` 的页面与 `portal/portal.js` 里;标题字体只裁了现有站名用到的字(见 `portal/fonts/README.md`),换站名要重新裁。
- **隐私扫描**:私有配置仓根目录放一份 `privacy_terms.txt`(一行一个:单位名称、域名、人名),
  `python scripts/privacy_scan.py` 会检查核心仓里有没有误写进去。往公开仓库提交前跑一次。

## 日常

- 程序每天 08:00(北京时间)自动更新;想立刻更新,在本机重跑第 4 步第 2 条命令。
- 备份、恢复、换域名、迁主机、令牌轮换见 [deploy/teable/README.md](../deploy/teable/README.md) 的「日常与运维」。
